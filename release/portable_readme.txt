自动送球 · 免安装版

版本：2026.09.12-gift8-portable
所有场景、按钮和 F 键标签的模板相似度门槛统一为大于 0.65。

双击“自动送球.exe”即可运行。无需安装软件或 Python。
请保留同目录的 _internal 文件夹，复制到其他位置时移动整个软件文件夹。

打开洛克王国，填写赠送次数（0 为不限），点击“开始赠送”后切回游戏。
球种、数量沿用游戏当前选择；赠送动作的 F 键自动识别。
窗口可以自由拖动，不停靠、不置顶。可暂停、继续、停止；关闭窗口也会停止。
运行中页面为绿色；暂停、异常或手动停止时变为橙色，并直接显示原因。
收藏页只识别 Esc 和选中的收藏分类；赠送文字全画面搜索，图标和 F 键跟随文字定位。

配置与日志自动保存在同目录 data 文件夹，升级时保留 data 即可。
右上角 ? 可检查状态。已有键鼠驱动时可直接使用。
其他电脑若缺少 Interception 驱动，仍需首次初始化并可能重启，这是驱动本身的要求。
支持 Windows 10/11 x64。
